Technical walkthrough · Bitcoin fraud screening

How the fraud screener was built, phase by phase

At a glance
  1. 1 · WhatA Bitcoin fraud detector: graph and tabular models score transactions, with a dashboard, an AI assistant and risk analytics.
  2. 2 · WhyIllicit payments hide in a 200,000-transaction graph; investigators need a ranked, explained shortlist instead of raw flows.
  3. 3 · WhoUsers: anti-money-laundering analysts and investigators.
  4. 4 · WhereResults page, technical walkthrough and transaction demo on GitHub Pages; dashboard on Streamlit Community Cloud; the API runs locally.
  5. 5 · When it failsChecked against the published benchmark first (illicit F1 within ±0.05 of 0.788): passed. A label inversion was found and fixed on the way.
  6. 6 · HowRandom forest on 166 features with the dataset authors' time split; GraphSAGE and GAT on the graph; a bandit picks the alert threshold.
Skills applied, with proof
  • Graph machine learning GraphSAGE and GAT on the transaction graph gnn_model.py advanced_gnn.py
  • Machine learning and evaluation random forest, time-based split, per-step F1, replication of the published benchmark ADR-004 evaluate_models.py
  • Reinforcement learning LinUCB contextual bandit for the alert threshold ADR-001 bandit.py
  • Quantitative risk Monte Carlo loss, value at risk, stress tests, Basel III capital risk_analysis.py regulatory_capital.py
  • GenAI and agents LangChain agent with 9 tools, retrieval over a fraud knowledge base fraud_agent.py rag_agent.py
  • Data engineering and services FastAPI service, medallion layers (document store and Postgres) ADR-002 ADR-003
  • CI/CD GitHub Actions lint and tests on every push; static demo on Pages ci.yml
